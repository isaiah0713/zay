# Isaiah Williams — Developer Portfolio

## Project description
A responsive professional portfolio website for Isaiah Williams, a Computer Science student. It presents an introduction, background, resume, selected projects, and contact information.

## How to update the site
Edit the HTML/CSS/JavaScript files, update project descriptions and GitHub links in `projects.html`, replace the placeholder email in `contact.html`, then commit changes to `main`.

## Technologies used
HTML5, CSS3, JavaScript, GitHub Pages, and GitHub Actions.

## Pages
Home • About • Resume • Projects • Contact

## Deployment
The site is configured for GitHub Pages.
